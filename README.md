# nolang

**Вероятность — это значение. Доверие решает, что агенту позволено.**

Маленький язык на чистом Common Lisp, где истина — не `bool`, а **градуированная, пересматриваемая пара `(f, c)`**: факт и уверенность в нём. Вывод даёт трёхсторонний вердикт — `passed` / `reachable` / `unreachable` — вместо бинарного вранья. Гейт честно говорит *«доказательств мало, зови человека»*, а не подбрасывает монету.

**Почему это важно.** LLM-агенты врут уверенно. Регуляторы (EU AI Act) требуют «человеческий надзор, соразмерный риску» — но надзор без формализма это театр. nolang — аудируемый слой между моделью и действием: belief течёт только от посчитанных свидетельств, никогда не самоназначается. Biject­ion Beta/Wang ≅ Jøsang-opinion — доказан, не провозглашён.

- Decidable. Terminating. **Unbribeable.**
- Валидатор LLM-вывода, каким не может быть ни regex, ни ML-классификатор.
- Написан на чистом Lisp — это принцип, не ностальгия: код как доказательство.

`nolang` проверяет ответ модели до того, как он достигнет пользователя. Код и модель покрывают провалы друг друга.
